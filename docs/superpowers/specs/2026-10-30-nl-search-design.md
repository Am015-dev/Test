# Αναζήτηση σε ελεύθερο κείμενο (Noikaki-style, αγορά) — design

Date: 2026-10-30 · Status: draft for review

## Στόχος
Σελίδα «Αναζήτηση» στο Streamlit dashboard: ο χρήστης γράφει με δικά του λόγια τι σπίτι
ψάχνει («δυάρι στον Χολαργό έως 180.000€, από 60 τ.μ., με ανελκυστήρα, μόνο από ιδιώτη»)
και βλέπει τις υπάρχουσες αγγελίες ταξινομημένες κατά **ταίριασμα %** με το «γιατί ταιριάζει».
Έμπνευση: noikaki.gr (ενοικίαση). Εδώ: **αγορά**, **προσωπική χρήση**.

## Εκτός scope (ρητά)
Λογαριασμοί/εγγραφή, συνδρομή/πληρωμές, Google login, push/email ειδοποιήσεις,
αποθηκευμένες αναζητήσεις, αλλαγές σε DB schema / collectors / scoring.
Μελλοντικά (φάση 2): αποθήκευση αναζήτησης + ειδοποίηση μέσω του υπάρχοντος Telegram (`alerts.py`).

## Κομμάτια
1. `src/scout/nl_search.py`
   - `SearchFilters` (pydantic): `areas: list[str]`, `price_min/max`, `area_min/max`,
     `bedrooms_min/max`, `floor_min`, `private_only: bool`, `wants: list[Literal["elevator",
     "parking","balcony","renovated"]]`.
   - `parse_query(text) -> SearchFilters`: κλήση Claude API (Haiku, structured output).
     Κόβει το κείμενο στους 500 χαρακτήρες. Σφάλμα API/άκυρη έξοδος → εξαίρεση
     `SearchParseError` (η UI δείχνει μήνυμα, ΔΕΝ επιστρέφει «όλες οι αγγελίες»).
   - `match(listing: dict, f: SearchFilters) -> tuple[int, list[str]] | None`:
     καθαρή συνάρτηση. Σκληρά κριτήρια (περιοχή, τιμή, τ.μ., υπνοδωμάτια, όροφος,
     ιδιώτης) — αποτυχία → `None` (αποκλεισμός). Άγνωστο πεδίο στην αγγελία δεν
     αποκλείει, δεν μετράει υπέρ. Μαλακά (`wants`) ανεβάζουν το ποσοστό (100% όταν
     όλα τα σκληρά περνούν και όλα τα wants επιβεβαιώνονται· άγνωστα wants μένουν
     ουδέτερα). Επιστρέφει λίστα λόγων.
2. `src/scout/ui/app.py`: νέα σελίδα — text area (500 χαρ.), κουμπί, chips με τα φίλτρα
   που κατάλαβε το σύστημα (διαφάνεια), κάρτες αποτελεσμάτων (τιμή, €/τ.μ., τ.μ., όροφος,
   πηγή, link, ποσοστό, λόγοι). Δεδομένα από το υπάρχον `get_listings()`.
3. `src/scout/config.py`: `anthropic_api_key: str = ""`. Κενό → η σελίδα δείχνει οδηγία,
   καμία κλήση. Όριο κλήσεων ανά session (π.χ. 20) για έλεγχο κόστους.
4. `requirements.txt` / `pyproject.toml`: εξάρτηση `anthropic`.

## Χαρακτηριστικά χωρίς δεδομένα
Το `Listing` δεν έχει πεδία ανελκυστήρα/πάρκινγκ/μπαλκονιού. Ο matcher ψάχνει λέξεις-κλειδιά
(ανελκυστήρας/ασανσέρ, πάρκινγκ/γκαράζ/θέση στάθμευσης, μπαλκόνι/βεράντα, ανακαινισμένο)
στον τίτλο (και στην περιγραφή αν υπάρχει στο dict). Καμία αλλαγή schema.
